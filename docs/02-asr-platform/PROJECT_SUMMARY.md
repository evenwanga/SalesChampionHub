## 🎯 项目概述

### 项目定义

**ASR语音分析平台**是一个基于CPU推理的销售通话分析系统，提供语音转文本、话术分析、质量评估和多租户数据隔离功能。

### 核心亮点

- ⚡ **CPU友好**: 无需GPU，基于ONNX Runtime的INT8量化模型
- 🎯 **销售专注**: 内置SPIN话术库、销售关键词典和质量评分算法
- 🔒 **数据安全**: 三层多租户隔离（应用层+RLS+存储层）
- 📊 **高准确率**: 中文CER <7%，英文WER <5%
- 💰 **成本可控**: 单次转录成本 <¥0.05/分钟

### 核心设计

1. **多租户隔离**: 三层防护（应用层JWT + 数据库RLS + 存储层bucket隔离）
2. **异步处理**: Redis Streams任务队列 + 多Worker并行
3. **CPU优化**: INT8量化 + 多线程推理 + 批处理 + 缓存
4. **数据安全**: TLS加密 + 存储加密 + 审计日志

### 数据库设计 (5张核心表)

- `audio_files`: 音频元数据
- `transcription_tasks`: 转录任务
- `transcription_results`: 转录结果
- `script_analysis`: 话术分析
- `quality_reports`: 质量报告

## 🤖 CPU友好型模型评估

### 候选模型对比 (5个)

| 模型 | 中文CER | RTF (CPU) | 模型大小 | 多语言 | 总分 |
|------|---------|-----------|---------|--------|------|
| **Whisper Large-v3** | 5.0% | 1.85 | 1.6GB | ✅ 98种 | **89** |
| **Paraformer-large** | 4.5% | 0.65 | 900MB | ❌ 仅中文 | **92** |
| **SenseVoice-small** | 5.2% | 0.55 | 900MB | ✅ 50种 | **88** |
| Whisper Small | 8.0% | 0.35 | 244MB | ✅ 98种 | 82 |
| Whisper Medium | 6.0% | 0.95 | 769MB | ✅ 98种 | 85 |

### 推荐方案

#### MVP阶段 (推荐⭐⭐⭐⭐)

**Whisper Large-v3-INT8 单模型**

- **理由**: 架构简单、快速上线、多语言、生态成熟
- **性能**: CER 5%，RTF 1.85，成本 ¥0.03/分钟
- **优化**: INT8量化 + 多线程 + 异步处理

#### 优化阶段 (推荐⭐⭐⭐⭐⭐)

**双模型架构 (Paraformer + Whisper)**

- **中文任务**: Paraformer-large (95%任务)
  - RTF 0.65, CER 4.5%, 成本 ¥0.011/分钟
- **英文/多语言**: Whisper Large-v3 (5%任务)
  - RTF 1.85, CER 5%, 成本 ¥0.031/分钟

- **收益**: 成本降低70%，准确率提升10%

### CPU优化策略

| 策略 | 效果 | 实施难度 |
|------|------|---------|
| **INT8量化** | 模型大小-75%，速度+2.5x | 低 |
| **多线程推理** | 吞吐量+3x (8核) | 低 |
| **批处理** | 吞吐量+50% | 中 |
| **缓存优化** | 重复任务+90% | 低 |
| **水平扩展** | 线性扩展 | 中 |

### 性能基准 (Intel Xeon 16核)

| 场景 | 配置 | 性能 |
|------|------|------|
| **单任务** | Whisper-large-v3-int8, 8线程 | 0.4x实时 (1分钟音频 → 2.5分钟) |
| **批量(10个)** | 同上 | 0.5x实时 (平均) |
| **多Worker(4个)** | 同上 | 1.6x实时 (并行) |
| **实时流式** | Whisper-base-int8 | 1.2x实时 (延迟<2秒) |
