## ✅ 子项目0: 用户中心（已完成）

### 项目概述

多租户统一用户中心是整个生态系统的身份认证和访问管理基础设施。

### 技术方案

- **框架**: Logto v1.33.0（开源认证框架）
- **数据库**: PostgreSQL 16
- **缓存**: Redis 7
- **部署**: Docker Compose
- **语言**: TypeScript/Node.js

### 核心功能

✅ **租户管理**
- 组织（Organization）创建和管理
- 租户配额管理
- 多租户数据隔离

✅ **用户管理**
- 用户注册/登录/登出
- 用户信息管理
- 用户-组织关系管理

✅ **身份认证**
- OAuth 2.1 / OIDC
- M2M (Machine-to-Machine) 认证
- JWT令牌管理
- SSO 单点登录

✅ **权限管理**
- RBAC（基于角色的访问控制）
- API Resources管理
- 组织级别角色

✅ **审计与安全**
- API审计日志
- 登录历史追踪
- 数据库Row-Level Security
