## 🔧 常用命令

### 服务管理
```bash
# 查看所有服务状态
docker-compose ps

# 查看日志
docker-compose logs -f [服务名]

# 重启服务
docker-compose restart [服务名]

# 停止所有服务
docker-compose down

# 启动所有服务
docker-compose up -d
```

### 数据库操作
```bash
# 连接数据库
docker-compose exec postgres psql -U postgres -d logto

# 查看表列表
docker-compose exec postgres psql -U postgres -d logto -c "\dt"

# 备份数据库
docker-compose exec postgres pg_dump -U postgres logto > backup.sql

# 恢复数据库
cat backup.sql | docker-compose exec -T postgres psql -U postgres logto
```

### 测试API
```bash
# Custom API健康检查
curl http://localhost:3003/health

# Logto端点测试
curl http://localhost:3001/.well-known/openid-configuration
```
