# 配置步骤 - 超详细版（带截图说明）

> 💡 这是最简单的方法！只需要复制粘贴几行命令。

---

## 📱 第一步：运行配置脚本

打开终端（Terminal），复制粘贴以下命令：

```bash
cd /Users/wangyiwen/produce/SalesChampionHub/projects/00-user-center
./scripts/setup-logto-simple.sh
```

按回车运行。

---

## 🔑 第二步：获取访问令牌（使用浏览器）

### 2.1 打开管理控制台

1. 在浏览器中访问：http://localhost:3002
2. 使用您创建的管理员账号登录

### 2.2 打开开发者工具

**方式1（推荐）：** 按键盘上的 `F12` 键

**方式2：**
- Mac: 按 `Command + Option + I`
- Windows/Linux: 按 `Ctrl + Shift + I`

**方式3：** 右键点击页面 → 选择"检查"或"Inspect"

### 2.3 在控制台中运行代码

1. 在开发者工具中，点击顶部的 **Console** (控制台) 标签

2. 在底部的输入框中，粘贴以下代码：

   ```javascript
   localStorage.getItem('logto:admin')
   ```

3. 按回车键

4. 您会看到一大串文字输出（类似这样）：
   ```
   "{"accessToken":"ey...很长的字符串...","refreshToken":"...", ...}"
   ```

5. **复制这整个输出**（包括最外层的引号）

### 2.4 粘贴到脚本

1. 回到终端
2. 脚本会提示："请粘贴刚才复制的字符串:"
3. 粘贴刚才复制的内容
4. 按回车

## ❓ 常见问题

### Q: 找不到 Console 标签？

**A**: 开发者工具的标签可能在顶部或底部，寻找：
- Console（英文）
- 控制台（中文）
- 或者一个 "> _" 图标

### Q: 粘贴代码后没有输出？

**A**: 可能需要：
1. 确保已经登录了管理控制台
2. 刷新页面后重新登录
3. 再次尝试运行代码

### Q: 输出的字符串很短或很奇怪？

**A**: 尝试运行另一个命令：

```javascript
JSON.parse(localStorage.getItem('logto:admin')).accessToken
```

这次只复制输出的令牌（不要引号），直接粘贴给脚本。

### Q: 脚本报错说无法解析？

**A**:
1. 确保复制了**完整的**输出，包括最外层的引号
2. 或者使用上面的替代命令，只获取accessToken部分
