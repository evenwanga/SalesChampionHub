# 超简单手动配置（5分钟完成）

> 💡 **完全不需要命令行！** 只需要在浏览器中点击几下就能完成！

---

## 🎯 我们要做什么？

只需要做 **1件事**：创建一个M2M应用，获得2个密钥

---

## 📝 配置步骤（跟着做就行！）

### 第1步：打开Logto管理控制台

1. 在浏览器中访问：http://localhost:3002
2. 用您的管理员账号登录（用户名：yiwenwang）

✅ **登录成功！** 您会看到Logto的主界面

---

### 第2步：创建M2M应用（最重要！）

#### 2.1 找到Applications

在左侧菜单栏，找到并点击：**Applications** （应用）

> 💡 如果是中文界面，可能显示为"应用"或"应用程序"

#### 2.2 创建新应用

点击右上角的按钮：**+ Create application** 或 **+ 创建应用**

#### 2.3 选择类型

在弹出的对话框中：
- 选择 **Machine-to-machine** （机器对机器）
- 或者图标是一个齿轮⚙️的那个

#### 2.4 填写信息

只需要填写应用名称：
```
User Center Custom API
```

其他都不用管！

点击 **Create** 或 **创建**

#### 2.5 复制密钥（超级重要！）

创建成功后，会看到一个页面显示：

```
App ID:          abc123def456...
App secret:      xyz789uvw012...
```

**请把这两个值复制下来！**

可以：
- 粘贴到记事本
- 或者截图保存
- 或者保持这个页面打开

---

### 第3步：更新配置文件

#### 3.1 打开配置文件

在项目文件夹中，找到并打开文件：
```
custom-api/.env
```

#### 3.2 修改两行

找到这两行：
```bash
LOGTO_M2M_APP_ID=
LOGTO_M2M_APP_SECRET=
```

改成（把刚才复制的值粘贴进去）：
```bash
LOGTO_M2M_APP_ID=abc123def456...     ← 粘贴您的App ID
LOGTO_M2M_APP_SECRET=xyz789uvw012... ← 粘贴您的App secret
```

#### 3.3 保存文件

按 `Ctrl+S` (Windows) 或 `Cmd+S` (Mac) 保存

---

### 第4步：重启服务

打开终端，运行：
```bash
cd /Users/wangyiwen/produce/SalesChampionHub/projects/00-user-center
docker-compose restart custom-api
```

等待10秒...

---

### 第5步：验证

在浏览器访问：
```
http://localhost:3003/health
```

应该看到：
```json
{
  "status": "healthy",
  "services": {
    "database": "up",
    "redis": "up"
  }
}
```

---

## 🎉 完成！

**就这么简单！** 您已经完成了核心配置！

## 📋 可选配置（不着急做）

如果您想要完整功能，还可以配置：

### 可选1：创建API Resource

<details>
<summary>点击展开步骤</summary>

1. 左侧菜单 → **API resources**
2. 点击 **+ Create API resource**
3. 填写：
   - API name: `Knowledge Base API`
   - API identifier: `https://api.saleschampionhub.com/kb`
   - Access token TTL: `3600`
4. 点击 **Create**
5. 进入该API → **Permissions** 标签
6. 点击 **+ Create permission**，添加：
   - `read` - Read knowledge base
   - `write` - Write knowledge base
   - `delete` - Delete knowledge base
   - `admin` - Admin knowledge base

</details>

### 可选2：创建用户角色

<details>
<summary>点击展开步骤</summary>

1. 左侧菜单 → **Roles**
2. 点击 **+ Create role**
3. 创建3个角色：

   **角色1**
   - Name: `owner`
   - Description: `Organization owner with full access`
   - Type: `User`

   **角色2**
   - Name: `admin`
   - Description: `Organization administrator`
   - Type: `User`

   **角色3**
   - Name: `member`
   - Description: `Organization member`
   - Type: `User`

</details>

### 可选3：创建测试组织

<details>
<summary>点击展开步骤</summary>

1. 左侧菜单 → **Organizations**
2. 点击 **+ Create organization**
3. 填写：
   - Name: `测试组织`
   - Description: `用于开发测试`
4. 点击 **Create**
5. 记下显示的组织ID（类似 `org_abc123`）

然后在终端运行（替换组织ID）：
```bash
docker-compose exec postgres psql -U postgres -d logto -c \
  "SELECT initialize_tenant_defaults('org_abc123', 'free');"
```

</details>

## ❓ 遇到问题？

### Q: 找不到Applications菜单？

**A**: 可能在不同位置，寻找：
- 应用
- Apps
- 或者一个 📱 图标

### Q: 创建应用后没有显示密钥？

**A**:
1. 点击刚创建的应用名称
2. 在应用详情页面会显示密钥

### Q: 忘记保存密钥了怎么办？

**A**:
1. 回到 Applications 列表
2. 点击您创建的应用
3. 密钥会在详情页显示
4. App secret可以重新生成

### Q: 重启服务后还是不健康？

**A**:
```bash
# 查看日志
docker-compose logs custom-api

# 确认密钥已更新
cat custom-api/.env | grep LOGTO_M2M
```
