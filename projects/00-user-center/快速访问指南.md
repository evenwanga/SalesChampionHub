**重要提示**: Logto和Custom API的根路径（`/`）不提供直接服务，必须访问具体的端点路径！

## API端点（程序调用）

### 1. OIDC/OAuth 认证端点

#### 1.1 发现文档（Discovery）
```bash
curl http://localhost:3001/oidc/.well-known/openid-configuration
```
**返回**: OpenID Connect配置信息

#### 1.2 获取访问令牌（M2M）
```bash
curl -X POST "http://localhost:3001/oidc/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=rd0j6xvios5fa68ymbjeg" \
  -d "client_secret=q49wZVhuqKzoCS7jpkRTQr8VDvMR3S5l" \
  -d "resource=https://api.saleschampionhub.com/kb" \
  -d "scope=read write"
```
**返回**: Access Token（访问令牌）

---

### 2. Custom API端点

#### 2.1 健康检查
```bash
curl http://localhost:3003/health
```
**返回**: 服务健康状态

#### 2.2 其他API端点
所有Custom API端点都需要访问具体路径，例如：
- `/api/quota/{organizationId}` - 查询组织配额
- `/api/audit-logs` - 查询审计日志
- 等等...

## 常见错误说明

### ❌ 错误1: 访问 `http://localhost:3001/`
**现象**: 重定向或404
**原因**: 这是Logto的UI入口，不是API端点
**解决**:
- 访问管理界面 → `http://localhost:3002`
- 访问API端点 → `http://localhost:3001/oidc/...`

### ❌ 错误2: 访问 `http://localhost:3003/`
**现象**: `{"success":false,"error":{"code":"NOT_FOUND","message":"Route GET / not found"}}`
**原因**: Custom API没有根路径路由
**解决**: 访问具体端点，如 `http://localhost:3003/health`

### ❌ 错误3: 忘记 `/oidc` 前缀
**现象**: 404 Not Found
**原因**: OIDC端点需要 `/oidc` 前缀
**正确**: `http://localhost:3001/oidc/.well-known/openid-configuration`
**错误**: `http://localhost:3001/.well-known/openid-configuration`

## 集成到代码示例

### Node.js
```javascript
const fetch = require('node-fetch');

// 获取访问令牌
async function getAccessToken() {
  const response = await fetch('http://localhost:3001/oidc/token', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/x-www-form-urlencoded',
    },
    body: new URLSearchParams({
      grant_type: 'client_credentials',
      client_id: 'rd0j6xvios5fa68ymbjeg',
      client_secret: 'q49wZVhuqKzoCS7jpkRTQr8VDvMR3S5l',
      resource: 'https://api.saleschampionhub.com/kb',
      scope: 'read write',
    }),
  });

  const data = await response.json();
  return data.access_token;
}

// 调用Custom API
async function callCustomAPI() {
  const token = await getAccessToken();

  const response = await fetch('http://localhost:3003/health', {
    headers: {
      'Authorization': `Bearer ${token}`,
    },
  });

  return await response.json();
}
```

### Python
```python
import requests

# 获取访问令牌
def get_access_token():
    response = requests.post(
        'http://localhost:3001/oidc/token',
        data={
            'grant_type': 'client_credentials',
            'client_id': 'rd0j6xvios5fa68ymbjeg',
            'client_secret': 'q49wZVhuqKzoCS7jpkRTQr8VDvMR3S5l',
            'resource': 'https://api.saleschampionhub.com/kb',
            'scope': 'read write',
        }
    )
    return response.json()['access_token']

# 调用Custom API
def call_custom_api():
    token = get_access_token()

    response = requests.get(
        'http://localhost:3003/health',
        headers={'Authorization': f'Bearer {token}'}
    )

    return response.json()
```

## 记住这些关键点

1. ✅ **管理界面**: 浏览器访问 `http://localhost:3002`
2. ✅ **API端点**: 必须包含完整路径，不能只访问根路径
3. ✅ **OIDC端点**: 需要 `/oidc` 前缀
4. ✅ **Custom API**: 访问具体路径如 `/health`
5. ✅ **使用令牌**: 所有受保护的API都需要 `Authorization: Bearer <token>` 头
