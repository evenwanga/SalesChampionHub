### 5. RAG 问答系统 (100%)

#### API 端点 (2个)
- ✅ **POST** `/api/v1/ask` - 标准 RAG 问答
- ✅ **POST** `/api/v1/ask-stream` - 流式 RAG 问答（SSE）

#### RAG 流程
1. ✅ 语义检索（BGE向量搜索）
2. ✅ 上下文构建（8000字符最大上下文）
3. ✅ LLM 生成（千问 Qwen）
4. ✅ 来源追溯（文档+分块信息）
5. ✅ 置信度计算（基于相似度）

#### 流式响应
- ✅ Server-Sent Events (SSE) 协议
- ✅ 实时内容流式传输
- ✅ 事件类型：sources, chunk, done, error
- ✅ Context 取消支持
- ✅ Goroutine 并发安全

#### LLM 集成
- ✅ 千问（Qwen）DashScope API
- ✅ 标准生成接口
- ✅ 流式生成接口
- ✅ Mock LLM（用于测试）
- ✅ 降级机制（LLM 失败时）
