  ```sql

  CREATE TABLE knowledge_bases (...);
  ```

  ```sql
  CREATE POLICY tenant_document_access ON documents USING (...);
  ```

## ⚠️ 注意事项

### 重要提醒

1. **RLS必须实施** - 数据库层面的安全保障不能省略
2. **完全依赖子项目0** - 不要重复实现认证/权限逻辑
3. **查询限制4个** - 初始阶段严格执行性能限制
4. **缓存策略** - Redis缓存TTL设置为5分钟
5. **组织数据来源** - 必须从子项目0获取，不要本地存储

### 常见问题

**Q: 为什么使用字段级隔离而不是Schema级？**
A: 简化实现，降低复杂度40%，配合RLS提供足够安全性

**Q: 为什么查询限制是4个知识库？**
A: 初始阶段控制性能，后续可根据实际情况调整

**Q: 组织结构如何获取？**
A: 完全从子项目0 API获取，不在本地存储
