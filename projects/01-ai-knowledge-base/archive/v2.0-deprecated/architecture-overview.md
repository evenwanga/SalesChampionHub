## 🔑 核心设计决策

### 1. 依赖子项目0: 统一用户中心 ⭐ 新增

**选择理由**:
- ✅ 避免重复开发（缩短开发周期20-30%）
- ✅ 统一身份管理（SSO单点登录）
- ✅ 集中权限控制（统一RBAC）
- ✅ 数据一致性（单一用户数据源）
- ✅ 统一审计日志

**集成方式**:
- Token验证：调用子项目0 API验证JWT
- 权限校验：调用子项目0 API检查权限
- 租户信息：通过API获取租户配置
- 降级方案：本地缓存 + JWT自验证

### 2. 租户隔离策略: Schema级隔离

**选择理由**:
- ✅ 最强的数据隔离（物理隔离）
- ✅ 性能无相互影响
- ✅ 符合企业数据安全要求
- ✅ 便于数据导出/迁移

**实现**:
```sql
-- 每个租户独立 Schema（仅知识库数据）
CREATE SCHEMA tenant_001;
CREATE SCHEMA tenant_002;

-- 运行时根据 JWT 中的 tenant_id 切换 Schema
SET search_path TO tenant_001;

-- 注意：用户数据在子项目0，不在本地
```

### 3. 基于 WeKnora 的扩展策略

**保留 WeKnora 核心**:
- 文档解析引擎
- 向量化处理
- RAG 问答能力
- 检索策略

**新增能力**:
- 多租户路由层
- 租户管理服务
- 企业级权限系统
- 配额与计费

### 4. 技术栈

| 组件 | 技术选型 | 理由 |
|------|---------|------|
| 后端框架 | Go | WeKnora 原生，高性能 |
| 前端框架 | React | WeKnora 原生 |
| 数据库 | PostgreSQL + pgvector | WeKnora 推荐 |
| 缓存 | Redis | 标准选择 |
| API网关 | Nginx | 轻量高效 |
| 认证 | JWT | 无状态，易扩展 |
| 容器化 | Docker | WeKnora 支持 |

## 📊 数据流图

### 查询请求流程

```
1. 客户端请求
   ↓
   POST /api/v1/query/ask
   Headers: Authorization: Bearer <jwt_token>
   Body: { "kb_id": "kb_123", "question": "..." }

2. API Gateway
   ↓
   - 提取 JWT Token
   - 调用子项目0验证Token (远程API调用)
   - 从响应获取: tenant_id, user_id, roles
   - 路由到后端

3. 权限校验（集成子项目0）
   ↓
   - 调用子项目0检查权限 (kb:read)
   - 检查 kb_123 是否属于 tenant_001 (本地校验)
   - 验证用户是否有访问权限

4. WeKnora 核心
   ↓
   - 设置 search_path = tenant_001
   - 在 tenant_001.knowledge_bases 中查询 kb_123
   - 在 tenant_001.vectors 中进行向量检索
   - 调用 LLM 生成答案

5. 返回结果
   ↓
   - 记录查询日志 (计费)
   - 返回答案给客户端
```

## 🛡️ 安全设计

### 多层安全防护

1. **网络层**: HTTPS + SSL证书
2. **接入层**: API Gateway 限流、防DDoS
3. **认证层**: 子项目0统一认证（JWT + OAuth2 + SSO）
4. **授权层**: 子项目0统一授权（RBAC权限控制）
5. **数据层**: Schema 物理隔离
6. **审计层**: 所有操作日志发送到子项目0

### 租户数据隔离保障

```go
// 中间件示例：租户隔离中间件（集成子项目0）
func TenantIsolationMiddleware(c *gin.Context) {
    token := extractToken(c)

    // 1. 调用子项目0验证Token
    user, err := userCenterClient.VerifyToken(token)
    if err != nil {
        c.JSON(401, gin.H{"error": "unauthorized"})
        c.Abort()
        return
    }

    // 2. 设置数据库 Schema
    db.Exec("SET search_path TO ?", "tenant_"+user.TenantID)

    // 3. 在上下文中存储租户信息
    c.Set("tenant_id", user.TenantID)
    c.Set("user_id", user.ID)

    c.Next()
}

// 所有查询自动限定在当前租户
// 无法跨租户访问数据
// 认证由子项目0保证
```
