# Agent任务：完善统计分析功能

**优先级：** P3 - 长期规划  
**预计工作量：** 6小时  
**影响范围：** 数据可视化和决策支持

---

## 任务目标

将现有的统计数据升级为完整的数据分析平台，提供可视化图表和深度洞察。

---

## 功能清单

### 1. 知识库统计分析
- 知识库使用频率趋势图
- 文档增长曲线
- 存储空间使用情况
- 热门知识库排行

### 2. 查询分析
- 查询量时间趋势（按小时/天/周/月）
- 搜索热词云图
- 查询响应时间分布
- 成功率统计

### 3. 用户行为分析
- 活跃用户统计
- 用户操作路径分析
- 功能使用热力图

---

## 实现建议

### 后端接口

```go
// GET /api/v1/stats/overview
// 返回总览统计

// GET /api/v1/stats/knowledge-bases/trend
// 返回知识库趋势数据

// GET /api/v1/stats/queries/analysis
// 返回查询分析数据

// GET /api/v1/stats/users/activity
// 返回用户活动数据
```

**使用图表库：** Recharts 或 Chart.js

**创建统计页面：**
- `src/pages/Analytics.tsx`

## 示例代码

```typescript
import { LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, Legend } from 'recharts'

export const QueryTrendChart: React.FC = () => {
  const { data } = useQueryStats({ 
    start_date: '2025-01-01', 
    end_date: '2025-12-31',
    group_by: 'day' 
  })

  return (
    <Card>
      <CardHeader>
        <CardTitle>查询趋势</CardTitle>
      </CardHeader>
      <CardContent>
        <LineChart width={600} height={300} data={data}>
          <CartesianGrid strokeDasharray="3 3" />
          <XAxis dataKey="period" />
          <YAxis />
          <Tooltip />
          <Legend />
          <Line type="monotone" dataKey="total_queries" stroke="#8884d8" />
        </LineChart>
      </CardContent>
    </Card>
  )
}
```
